# Giellatekno's korp-vue instance

The Korp frontend is Språkbanken's [korp-vue](https://github.com/spraakbanken/korp-vue)
(Vue 3; the old korp-frontend is deprecated), built per language with this
directory as its `instance/` (see korp-vue's `docs/ARCHITECTURE.md` and
`docs/INSTANCE.md`). `manage build front <lang>` builds it
(`manage/containerfiles/Containerfile.frontend`, which also pins the korp-vue
commit), and `manage deploy <lang>` serves it from the language's Worker.

- `settings.ts`: the settings, read from `config.yml`, which the build copies
  from `gtweb2_config/front/config-<lang>.yaml`. Sets `korp_backend_url` to
  `api` next to the page, computed in the browser, so the same build works on
  workers.dev and behind a reverse proxy.
- `plugin.ts`: replaces the header's right-hand logos (`components/BrandSecondary.vue`:
  UiT, Giellatekno) and the footer (`components/FooterContent.vue`, instead of
  Språkbanken's).
- `locale/<lang>.yaml`: UI strings, one file for every language a config lists
  in `languages` (the build fails without it). `eng.yaml` overrides korp-vue's
  English strings that name Språkbanken. The others are generated by
  `port-translations.py` from our old korp-frontend translations
  (`gtweb2_config/translations/locale-<lang>.json`), matched by English text:
  about 145 of korp-vue's ~330 strings; the rest show in English. Hand-edits
  are lost if the script is run again.

Not ported yet: `gtweb2_config/translations/corpora-<lang>.json` (translated
attribute values, e.g. deprel), and the `angular-locale_*.js` files (AngularJS
only, not needed).
